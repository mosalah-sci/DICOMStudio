# Documentation

The documentation tree complements the governing documents stored at the
repository root (`PROJECT_CONSTITUTION.md`, `IMPLEMENTATION_ROADMAP.md`,
`CODING_STANDARDS.md`, `UI_BLUEPRINT.md`, `AI_DEVELOPMENT_RULES.md`,
`MILESTONE_PROMPT_FRAMEWORK.md`).

```
docs/
├── architecture/   Architecture Decision Records (ADRs)
├── design/         UI/UX design material (mockups, interaction notes)
└── user/           End-user documentation
```

## Architecture Decision Records

Every significant architectural decision is recorded in
`docs/architecture/` as an ADR (ADR-NNN.md). The index and process are
described in `docs/architecture/README.md`.

## Design

UI/UX design documents (mockups, interaction specifications) are collected
here. The first artifacts land with the Application Shell milestone.

## User

End-user documentation is authored during the release cycle.
