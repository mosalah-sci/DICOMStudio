# ADR-008: DICOM Library Ownership

Status: Accepted
Date: 2026-08-03

## Context

Both pydicom and SimpleITK can read DICOM pixel data. Overlapping ownership
would produce duplicated logic and inconsistent behavior.

## Decision

- **pydicom** owns metadata parsing and pixel extraction.
- **SimpleITK** is the optional, lazy-loaded fallback for robust decoding and
  later medical transforms, added only when it adds real value.
- DICOM access happens exclusively through Infrastructure adapters.

## Consequences

- A single, consistent path for metadata and pixels.
- No duplicated DICOM logic across modules.
- The fallback can be introduced without changing use cases.
