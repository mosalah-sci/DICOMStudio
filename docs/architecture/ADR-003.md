# ADR-003: Manual Composition Root and Dependency Injection

Status: Accepted
Date: 2026-08-03

## Context

The constitution mandates dependency injection and explicit dependencies
without requiring a specific mechanism. A DI framework would add an
unjustified dependency.

## Decision

- A single composition root lives in `dicomviewer/main.py`.
- All dependencies are provided through constructor injection.
- No DI framework is used.
- Components never instantiate their own infrastructure directly.

## Consequences

- The object graph is assembled in one reviewable place.
- Every component is testable by substituting fakes through the constructor.
- The dependency count stays minimal.
