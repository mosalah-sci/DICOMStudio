# ADR-013: Qt Application Lifecycle and High-DPI

Status: Accepted
Date: 2026-08-03

## Context

Process-wide Qt attributes must be set before `QApplication` is constructed,
and Windows high-DPI behavior must be correct from day one.

## Decision

- A dedicated `_prepare_qt_environment()` hook runs before the
  `QApplication` is created, providing a single place for platform setup.
- Qt 6 enables high-DPI scaling and pixmaps by default, so no attributes are
  required today; the hook keeps the ordering guaranteed.
- Application metadata (name, version, organization) is set on the
  `QApplication` instance.

## Consequences

- High-DPI rendering cannot silently regress through ordering mistakes.
- Platform setup has one well-defined location.
