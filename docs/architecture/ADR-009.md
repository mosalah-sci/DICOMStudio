# ADR-009: Domain Entities and Identity

Status: Accepted
Date: 2026-08-03

## Context

The study hierarchy (Patient, Study, Series, Instance) must be represented in
a way that remains stable as PACS and plugin features arrive.

## Decision

- Domain entities are immutable dataclasses keyed by DICOM UIDs.
- UIDs are wrapped in a validated `DicomUid` value object.
- Repositories are declared as ports; no ORM or database is used in v1.

## Consequences

- Entity identity is unambiguous and framework-independent.
- The domain model can be extended without redesigning the core.
- Persistence decisions stay in Infrastructure.
