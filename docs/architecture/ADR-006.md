# ADR-006: Configuration Strategy

Status: Accepted
Date: 2026-08-03

## Context

The constitution specifies TOML configuration. Python's standard `tomllib`
is read-only, so writing user settings requires a TOML writer.

## Decision

- Defaults are bundled with the package as `defaults.toml`.
- User overrides are stored in a `settings.toml` under the user config
  directory and merged over the defaults.
- `tomlkit` handles parsing and safe, round-trip-preserving writes.
- Settings are represented as immutable, typed dataclasses with validation.

## Consequences

- The configuration surface is typed and validated instead of a string soup.
- Adding a new section later is backward-compatible.
- `tomlkit` is a justified addition to the dependency set.
