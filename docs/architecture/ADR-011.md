# ADR-011: Versioning and Release Tagging

Status: Accepted
Date: 2026-08-03

## Context

The roadmap defines twelve milestones but its version example is incomplete
and contradicts the milestone order.

## Decision

- Semantic versioning with a single version source in `_version.py`, read by
  hatchling for packaging.
- Milestone tags: `v0.1.0` … `v0.12.0` for Milestones 1–12, then `v1.0.0`
  for production release.
- Every completed milestone ends with a tagged, runnable state.

## Consequences

- Version drift between packaging and runtime is impossible.
- Each milestone is reproducible from its tag.
- The roadmap's release table is reconciled with its milestone list.
