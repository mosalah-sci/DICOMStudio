# ADR-007: Framework Rules for the Domain Layer

Status: Accepted
Date: 2026-08-03

## Context

The coding standards forbid Qt, VTK and OpenCV inside the Domain layer, while
NumPy is part of the stack and pixel math belongs to the domain of pure
computations.

## Decision

- The Domain layer never imports Qt, VTK or OpenCV.
- OpenCV and SimpleITK implementations live in Infrastructure behind Domain
  ports (for example `ImageProcessingService`).
- NumPy is permitted in Domain for pure mathematical operations.

## Consequences

- Domain logic stays deterministic and testable without heavy dependencies.
- The coding-standards constraint and the technology stack coexist cleanly.
