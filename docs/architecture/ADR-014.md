# ADR-014: UI Theming Approach

Status: Accepted
Date: 2026-08-03

## Context

The UI blueprint specifies a dark-mode default and consistent design language
with future high-contrast and light themes.

## Decision

- Theming is applied through a `ThemeProvider` (QPalette plus stylesheets).
- The active theme is a configuration value, defaulting to `dark`.
- Visual constants follow the 8-pixel spacing grid and Segoe UI typeface.

## Consequences

- Theme switching is a configuration change, not a code change.
- The theme system is introduced with the Application Shell milestone.
