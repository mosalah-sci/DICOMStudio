# ADR-010: Error Handling Strategy

Status: Accepted
Date: 2026-08-03

## Context

The coding standards require specific exception handling and user-friendly
error presentation without exposing internals.

## Decision

- A single `DicomViewerError` root exists in the Domain layer; every
  application and infrastructure error derives from it.
- Exceptions are caught as specifically as possible; no bare `except`.
- The Presentation layer maps exceptions to user messages; technical detail
  is written to logs only.

## Consequences

- Known failures are handled uniformly at the boundary.
- Users never see stack traces; logs retain the technical context.
- The application fails gracefully instead of freezing.
