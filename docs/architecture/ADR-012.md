# ADR-012: Testing Strategy

Status: Accepted
Date: 2026-08-03

## Context

The project demands independent, deterministic and fast tests with no real
patient data and no external state.

## Decision

- Domain and Application: fast pure-Python unit tests.
- Infrastructure: integration tests against temporary directories.
- UI: pytest-qt widget tests, introduced when the first widget ships.
- Qt-dependent tests run headless through the `offscreen` platform.
- Fixtures generate synthetic DICOM data at runtime.

## Consequences

- Tests are deterministic and run anywhere, including CI.
- No sensitive data ever enters the repository.
- Test speed keeps the inner loop tight.
