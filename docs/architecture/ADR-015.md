# ADR-015: Import Discipline and Startup Performance

Status: Accepted
Date: 2026-08-03

## Context

Fast startup is a product goal. Heavy modules (numpy, pydicom, imaging
libraries) must not make the application feel slow to open.

## Decision

- Heavy libraries are imported lazily inside functions when they are not
  needed at import time of the importing module.
- The composition root imports only what it needs to start the shell.
- Future milestones profile and optimize based on measured bottlenecks.

## Consequences

- Cold-start time stays predictable.
- Import-time work is explicit and reviewable.
- No premature micro-optimization is introduced.
