# ADR-002: Package Naming and src Layout

Status: Accepted
Date: 2026-08-03

## Context

The application needs a stable import package and a repository layout that
prevents accidental imports of tests and enforces correct packaging.

## Decision

- Import package: `dicomviewer` (single word, lowercase).
- Source layout: all code under `src/dicomviewer/`; tests under `tests/`.
- Distribution name and console script also use `dicomviewer`.
- Displayed application name: "DICOM Viewer Professional".

## Consequences

- Importing the package from outside the workspace requires installation,
  which matches how the application is deployed.
- The package name maps cleanly to the console script and future
  PyInstaller executable.
