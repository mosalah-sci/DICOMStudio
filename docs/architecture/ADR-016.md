# ADR-016: File and Function Size Discipline

Status: Accepted
Date: 2026-08-03

## Context

The coding standards cap file size and function length to keep the codebase
readable and cohesive.

## Decision

- Source files stay below 500 lines; functions stay below 40 lines.
- One class per file unless classes are provably inseparable.
- Modules that outgrow their responsibility are split into focused modules.

## Consequences

- The codebase stays navigable and reviewable.
- Responsibilities remain visible and enforced by convention.
