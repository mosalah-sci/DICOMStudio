# ADR-005: Logging Strategy

Status: Accepted
Date: 2026-08-03

## Context

The project mandates structured logging with Loguru and forbids exposing
patient-identifiable information in logs.

## Decision

- Loguru is used directly in every layer; no logging abstraction is created.
- Logs go to the console and to rotating files under the user log directory.
- A privacy policy forbids patient-identifiable content in log messages;
  compliance is enforced through code review.

## Consequences

- No value-less abstraction is introduced.
- The rotating file configuration keeps disk usage bounded.
- Privacy is a review gate, not an afterthought.
