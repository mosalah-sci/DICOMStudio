# Design Documentation

UI/UX design material for the DICOMStudio interface is
collected in this directory: mockups, interaction specifications, and notes
derived from `UI_BLUEPRINT.md`.

The first artifacts landed with the Application Shell milestone:

- `m2-application-shell-dark.png` — the completed shell in the default dark
  theme.
- `m2-application-shell-light.png` — the same shell in the light theme.

These screenshots capture the main window layout, docking system and theme
support introduced by the Application Shell milestone.
